# Rick Dangerous — installation

Requires Retro-Go SD **v2.0.0-rc1 or later** on the Game & Watch.

1. Copy the `homebrews` folder of the zip to the SD card's root:

       /homebrews/RickDangerous.bin
       /homebrews/RickDangerous.xrk

   Both files side by side, with the same name.

2. Start "Rick Dangerous" from the Homebrew tab. The first start copies
   the pack (3.4 MB) to the external flash ("Caching game file").

Controls: D-pad = walk / climb / crawl, A = fire (with up: shoot, with
down: bomb, with left/right: stick; also starts the game), B = jump, GAME
or TIME = pause, PAUSE/SET = Retro-Go menu (save states). High scores:
`/retro-go/saves/xrick/`.

# Rick Dangerous — installation (français)

Nécessite Retro-Go SD **v2.0.0-rc1 ou plus récent** sur la Game & Watch.

1. Copier le dossier `homebrews` du zip à la racine de la carte SD :

       /homebrews/RickDangerous.bin
       /homebrews/RickDangerous.xrk

   Les deux fichiers côte à côte, avec le même nom.

2. Lancer « Rick Dangerous » depuis l'onglet Homebrew. Au premier
   lancement, le pack (3,4 Mo) est copié dans la flash externe (« Caching
   game file »).

Commandes : croix = marcher / grimper / ramper, A = action (avec haut :
tirer, avec bas : bombe, avec gauche/droite : coup de bâton ; lance aussi
la partie), B = sauter, GAME ou TIME = pause, PAUSE/SET = menu Retro-Go
(sauvegardes). Meilleurs scores : `/retro-go/saves/xrick/`.
